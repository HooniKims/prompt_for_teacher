# 질문형 프롬프트 가이드

교사가 만들고 싶은 웹앱, 프로그램, 수업 자료, 평가 자료, 학교 업무 자료를 더 좋은 AI 실행용 프롬프트로 정리해 주는 브라우저 기반 도구입니다.

핵심 문장은 **“AI 이전 사람 있고, AI 이후 사람 있다”**입니다.  
AI가 바로 결과를 대신 만드는 것보다, 교사의 생각과 판단 지점을 먼저 정리한 뒤 AI가 실제로 실행하기 좋은 프롬프트를 만드는 데 초점을 둡니다.

## 무엇을 해주나요?

- 교사가 짧게 적은 아이디어를 질문으로 구체화합니다.
- 10단계 확인 흐름으로 빠뜨리기 쉬운 조건을 점검합니다.
- 최종 결과를 `교사용 요약`, `AI 실행용 프롬프트`, `참고 안내`로 나누어 보여줍니다.
- 개인정보보호와 학습지원 소프트웨어 심의 관련 확인 사항을 따로 정리합니다.
- 초보 교사도 이해하기 쉬운 말로 안내합니다. 서버, DB, 백엔드 같은 개발 용어 대신 "다음에 열어도 남아 있어야 하나요?", "여러 사람이 같이 접속하나요?"처럼 묻습니다.
- 답변에 따라 가장 단순한 기술 방향(브라우저만 / 내 컴퓨터 저장 / 서버와 데이터베이스)과 보안 기본(비밀키 분리, 서버 권한 검사, 입력 검증, 백업, 최소 수집)을 최종 프롬프트에 넣습니다.
- 모바일에서도 채팅 중심으로 사용할 수 있습니다.
- 대화 중에는 **지금까지 내용으로 완성하기** 버튼으로 남은 질문을 건너뛰고 프롬프트를 만들 수 있습니다. 빠진 항목은 프롬프트에 "아직 확인하지 않음"으로 표시됩니다.
- 입력창 아래의 **처음부터 다시 시작하기** 링크로 언제든 새 작업을 시작할 수 있습니다.

## 어떻게 쓰나요?

1. 처음 화면에 만들고 싶은 자료, 앱, 프로그램, 문서를 한두 문장으로 적습니다.
2. 이어지는 질문에 답하면서 수업 장면, 대상, 목표, 필요한 자료, 개인정보 여부, 저장·접속 방식을 정리합니다. A, B, C 중 하나를 고르거나 직접 문장으로 답하면 됩니다. 글자 `A`만 보내도 그 선택지가 골라집니다.
3. 질문은 왼쪽 목록 순서대로 이어지며, 직전 답을 받아서 다음을 묻습니다. 앱을 만들 때는 개인정보와 저장 방식을 3번째 질문 안에 먼저 확인합니다. 답변이 부족하면 더 자세히 묻고, 전체 답변은 15번을 넘지 않습니다. 개인정보 처리방침이나 약관 문구는 묻지 않고 프롬프트에서 초안으로 만들게 합니다.
4. 기본 10개가 끝나면 마무리 3개(이번에 만들 범위, 우선순위, 성공 기준)를 묻습니다. 이때는 AI가 대화 내용으로 추천안을 만들어 첫 선택지로 보여주므로 A만 골라도 됩니다. 건너뛰면 개발 AI가 추천안을 먼저 제시하고 선생님 확인을 받도록 프롬프트에 적힙니다. 왼쪽 목록과 오른쪽 "지금까지 확인한 내용"에서 어떤 항목이 채워졌는지 볼 수 있습니다.
5. 오른쪽 완성본에서 `교사용 요약`, `AI 실행용 프롬프트`, `참고 안내`를 확인하고 필요한 부분을 복사합니다.
6. 다른 작업을 시작하려면 채팅 입력창 아래의 **처음부터 다시 시작하기**를 누릅니다.

## 최종 결과 구조

### 1. 교사용 요약

교사가 빠르게 확인할 수 있는 쉬운 요약입니다.

- 만들 것
- 사용 장면
- 대상과 맥락
- 목표
- 선생님이 직접 정할 것
- 개인정보, 저장과 접속, 기술 방향
- 이번 범위, 우선순위, 성공 기준
- 아직 확인하지 않은 항목은 "아직 확인하지 않음"으로 표시

### 2. AI 실행용 프롬프트

개발 AI가 바로 작업할 수 있도록 상세하게 작성됩니다.

포함되는 내용:

- 역할과 상황 (프롬프트는 [역할]로 시작합니다)
- 범위, 우선순위, 성공 기준 (정하지 않았으면 개발 AI가 추천안을 먼저 제시)
- 기술 방향과 보안 기본 (앱을 만들 때)
- 요구사항 정의
- 화면 흐름
- 기능별 모듈
- 데이터 모델
- 권한 설계
- 개인정보보호 구현 계획
- 학습지원 소프트웨어 심의 대응 구현 계획
- 테스트 기준
- 완료 기준

### 3. 참고 안내

교사가 실제 서비스로 쓰기 전에 확인할 내용을 따로 보여줍니다.

특히 다음 기준을 반영합니다.

- 교사 단독 행정·업무·수업 준비용 도구는 보통 심의 제외
- 정규 수업에서 학생과 함께 쓰며 개인정보를 수집·처리하면 심의 필요
- 개인정보를 전혀 수집하지 않는 단순 수업용 웹앱이나 체험 콘텐츠는 심의 제외 가능
- 교사 자체 개발 수업용 도구가 개인정보를 수집하면 교사가 개인정보 보호 5개 필수 기준 체크리스트나 서술형 증빙을 준비

## 주요 기능

- `친절` 모드와 `꼼꼼` 모드 선택
- 기본값은 `꼼꼼` 모드
- 현재 진행 단계 표시 (답변 횟수가 아니라 실제로 확인된 항목 기준)
- AI가 답을 준비하는 동안 대화창에 진행 표시
- 저장한 작업 다시 불러오기
- 이전에 만든 프롬프트 참고
- 엔터로 보내기, Shift+Enter로 줄바꿈
- 선택지 글자(A, B, C, D)만 입력해도 선택
- 지금까지 내용으로 완성하기, 처음부터 다시 시작하기
- 교사용 요약과 AI 실행용 프롬프트 각각 복사
- 라이트/다크 모드
- OpenAI `gpt-5.4-nano` 지원 (화면에는 "OpenAI"로 표시)
- LM Studio/OpenAI-compatible 로컬 모델 지원 (화면에는 "학교 AI"로 표시)

## 실행 방법

```bash
npm run dev
```

브라우저에서 아래 주소로 접속합니다.

```text
http://127.0.0.1:5173/
```

## 환경 변수

프로젝트 루트에 `.env` 파일을 만들고 필요한 값을 넣습니다.  
`.env`는 GitHub에 올리지 않습니다.

### OpenAI 사용

```env
OPENAI_API_KEY=여기에_API_키
OPENAI_MODEL=gpt-5.4-nano
```

### LM Studio 사용

```env
LMSTUDIO_API_URL=http://lm.alluser.kr:1234
LMSTUDIO_API_KEY=필요한_경우에만_입력
LMSTUDIO_GEMMA_E4B_MODEL=google/gemma-4-e4b
```

`.env`를 바꾼 뒤에는 `npm run dev`를 다시 실행해야 새 주소로 연결됩니다.

로컬 개발 서버는 `/openai/v1`과 `/v1` 프록시를 제공합니다.

## Netlify 배포 환경 변수

Netlify에 배포할 때는 사이트 설정의 Environment variables에 아래 값을 추가합니다.

```text
OPENAI_API_KEY
OPENAI_MODEL
LMSTUDIO_API_URL
LMSTUDIO_API_KEY
LMSTUDIO_GEMMA_E4B_MODEL
```

기본 OpenAI 모델은 `gpt-5.4-nano`입니다.
